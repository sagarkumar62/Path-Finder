## 2. Dataset Processing Pipeline Stages

```text
1. Raw Dataset Ingestion
   [ai-service/app/data/raw/esco & onet]
                    │
                    ▼
2. Data Preprocessing & Skill Normalization
   [skill_normalizer.py & dataset_cleaner.py]
   - Normalizes "Python programming" -> "Python"
   - Clamps importance weights (0.0 to 1.0) and required levels (1 to 5)
                    │
                    ▼
3. Processed Unified Knowledge Base
   [ai-service/app/data/processed/careers.json]
   - Career ↔ Skill relationships & DAG prerequisite dependencies
                    │
                    ▼
4. Sentence Transformers Vector Embeddings
   [all-MiniLM-L6-v2 (384 dimensions)]
                    │
                    ▼
5. Persisted FAISS Vector Index
   [ai-service/app/data/embeddings/careers.index & metadata.json]
   - Fast O(1) similarity retrieval
                    │
                    ▼
6. Deterministic 4-Phase Roadmap Engine
   [roadmap_engine.py & skill_graph.py]
   - Phase 1: Foundations & Prerequisites
   - Phase 2: Core Technical Mastery
   - Phase 3: Advanced Specialization
   - Phase 4: Capstone Projects & Career Readiness
                    │
                    ▼
7. Generative LLM Resource & Mentor Enrichment
   [Google Gemini gemini-3.6-flash via @google/genai]
   - Enriches each phase with Video 🎥, Docs 📄, and Project 🚀 resources
   - Generates Mermaid flowcharts & capstone project specifications
```

## 3. Key Terminology & Architectural Principles

- **Career Knowledge Dataset / Benchmark Dataset**: The processed data stored in `ai-service/app/data/processed/` is used for Retrieval-Augmented Generation (RAG), weighted skill gap scoring, and prerequisite DAG graph ordering.
- **Vector Indexing (Not Model Retraining)**: Pretrained `sentence-transformers/all-MiniLM-L6-v2` converts career summaries into 384-dimensional dense vectors stored in FAISS (`ai-service/app/data/embeddings/careers.index`).
- **Gemini Responsibility**: Gemini enriches and explains structured facts generated by the Python roadmap engine without inventing baseline prerequisites or altering deterministic phase sequences.
