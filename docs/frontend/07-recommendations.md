# 07 & 10 — Recommendations & Roadmap Specification

## Recommendations (`/recommendations`)
- Displays career path cards sorted by AI match fit score (`AI Engineer 87% Match`, `Full Stack AI Developer 82% Match`, `Data Scientist 74% Match`).
- Each card highlights match rationale, target skill gaps, difficulty, and estimated transition timeline.
- Features a side-by-side career comparison drawer comparing match scores, difficulty, timelines, and average salaries.

---

## Personalized Adaptive Roadmap (`/roadmap`)
- Presents a 5-phase career timeline:
  - Phase 1: Python Core & Data Structures (Completed)
  - Phase 2: Mathematics & Statistics for AI (Active Phase - 75% Complete)
  - Phase 3: Machine Learning Fundamentals
  - Phase 4: Deep Learning & Neural Networks
  - Phase 5: Production AI Capstone & RAG System
- **Adaptive Recalibration Alert**: Shows dynamic system notices when timeline adjustments occur (*"⚡ Adaptive Learning Adjustment Triggered: Statistics phase extended by 1 week based on recent activity"*).
- **Checkable Milestones**: Instant state mutation and progress updates upon milestone completion.
