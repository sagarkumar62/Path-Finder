# 11 & 13 — Dashboard & AI Assistant Specification

## Dashboard (`/dashboard`)
- Primary authenticated home acting as a **Personal Career Command Center**.
- Displays greeting *"Good evening, Sagar — You're on track to become an AI Engineer"*.
- Metrics Cards: Active Goal (87% Fit), Overall Progress (42%), Recorded Study Time (38.5 hrs), Active Streak (6 Days).
- Next Action Card: Prominent banner featuring *"Complete: Linear Regression Basics"*.
- Recommended resources grid & skill gap overview breakdown.

---

## AI Assistant (`/assistant`)
- `CareerPath AI` conversational interface designed as a personal career mentor.
- Includes a persistent **Learner Context Panel** displaying active goal (`AI Engineer`), current phase (`Phase 2: Math & Statistics`), and target skill gaps.
- Quick prompt chips (`"What should I learn next?"`, `"Why is AI Engineering a good fit for me?"`, `"Give me a project to practice ML"`).
- Embedded action cards in AI responses allowing users to add practice items directly to their roadmap.
