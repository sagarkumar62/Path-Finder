# 05 & 06 — Onboarding & AI Analysis Specification

## Purpose
The Onboarding experience (`/onboarding`) is a multi-step conversational wizard that gathers learner skills, interests, education, experience, goals, learning preferences, and weekly time availability before launching the AI analysis processing engine.

---

## Workflow Steps
1. **Background**: Education level dropdown & Experience level pills (`Entry`, `Mid`, `Senior`, `Lead`).
2. **Skills Matrix**: Selectable skill badges (`JavaScript`, `Python`, `React`, `Node.js`, etc.) with proficiency selectors (`Beginner`, `Intermediate`, `Advanced`).
3. **Interests**: Visual selection cards (`AI & Machine Learning`, `Web Development`, `Data Science`, `Cloud Architecture`, etc.).
4. **Career Goals**: Target role text input (`AI Engineer`) and motivation text.
5. **Learning Formats**: Resource preference chips (`Projects`, `Interactive`, `Videos`, `Docs`, `Courses`).
6. **Time Commitment**: Interactive slider for weekly study hours (`5` to `30` hrs/week).
7. **AI Analysis Processing**: Intelligent stage-by-stage processing animation (*"Analyzing your skill matrix"*, *"Mapping career market demand"*, *"Evaluating skill gap delta"*, *"Building adaptive learning roadmap"*) before displaying CTA to see recommendations.
