# CAREER PATHFINDER

> AI-Powered Personalized Career and Learning Path Recommendation SaaS (Hackathon Prototype)

## Repository Structure

- [`server/`](file:///c:/Users/hp/OneDrive/Documents/Desktop/Path%20Finder/server) - Node.js + Express + TypeScript Backend API
- [`docs/`](file:///c:/Users/hp/OneDrive/Documents/Desktop/Path%20Finder/docs) - Solution & Feature Architecture Documentation (00 to 17)
- `ai-services/` - Python FastAPI AI Microservice (Developed separately)
- `client/` - Next.js Frontend (Developed separately)

## Quick Start (Backend Server)

```bash
cd server
npm install
npm run seed
npm run dev
```

Server running at: `http://localhost:5000/api/v1/health`
